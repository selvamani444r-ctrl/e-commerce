# Nexus Nook — Discover More. Shop Smarter.

**Nexus Nook** is a high-conversion, professional affiliate marketing & price comparison marketplace. Built to deliver the usability, speed, and product discovery experience of major platforms (like Amazon & Flipkart), while sporting a 100% original visual identity, brand geometry, color system, and editorial testing standards.

---

## 🌟 Key Platform Features

1. **Brand Identity & Color System**:
   - **Deep Navy** (`#0B1220`) navigation & dark surfaces.
   - **Electric Blue** (`#2563EB`) interactive actions and links.
   - **Lime Green** (`#84CC16`) deal/savings highlights.
   - Original geometric "N" symbol integrated with shopping nexus node and lime deal indicator.
   - Inter & Plus Jakarta Sans typography with clean whitespace and smooth card hover lifts.
   - Full **Dark Mode** toggle persisted in `localStorage`.

2. **Affiliate Marketing & Monetization Architecture**:
   - Primary conversion action: **“View Deal”** / **“Check Price”** (Never fake checkout).
   - Configurable affiliate tracking URLs per merchant (`amazon-21`, `fk-aff`, `croma`, `reliancedigital`, `myntra`, `tatacliq`).
   - Transparent redirection modal informing users of coupon verification and affiliate commission notice before opening the partner store in a new tab.
   - Outbound click tracker that records timestamped affiliate clicks.

3. **Homepage Sections (Structured Flow)**:
   1. **Announcement Bar** (Live flash drops, affiliate disclosure, CMS tracker, dark mode toggle).
   2. **Sticky Header** (Original Logo, Smart search bar with autocomplete suggestions, voice search & image camera triggers, location badge, wishlist & compare counters).
   3. **Mega Menu** (Multi-column department flyout with top tech, home, beauty, and popular brand pills).
   4. **Hero Section** (“Discover Products You’ll Love”, floating product cards, verified comparison badges).
   5. **Trust Bar** (Line icons for 5 core trust pillars).
   6. **Shop by Category** (18 department cards with counts & hover animations).
   7. **Trending Right Now** (Dynamic filterable carousel/grid with deal scores).
   8. **Today’s Best Deals** (Live countdown timer HH:MM:SS, % claimed progress bars).
   9. **Compare Before You Buy** (Side-by-side merchant price comparison table with shipping & return terms).
   10. **Featured Collections** (10 handpicked shopping collections).
   11. **Deal of the Day** (Urgency timer, savings calculator, large showcase).
   12. **Explore Popular Brands** (Apple, Samsung, Sony, Nike, HP, Dell, etc.).
   13. **Picked For You** (Dynamic recommendation engine using browsing history & wishlist).
   14. **Recently Viewed** (Dynamic local history strip with clear history action).
   15. **Product Discovery & Deal Finder** (Sidebar filters: category, brand, price slider, rating, discount, merchant, sort modes, grid/list view).
   16. **Smart Shopping Guides** (Full editorial article reader modal).
   17. **VIP Deal Newsletter** (Email subscription with instant feedback toast).
   18. **Footer & Trust Area** (5 columns, social icons, complete FTC/affiliate legal disclosure).

4. **Modals & Drawers**:
   - **Product Detail Modal**: Multi-image thumbnail gallery, specifications table, pros & cons breakdown, multi-merchant comparison table, and Price Drop alert trigger.
   - **Product Comparison Modal**: Side-by-side spec & price comparison for up to 4 selected products.
   - **Wishlist Drawer**: Manage saved items, compare, or trigger merchant deals.
   - **Price Drop Alert Modal**: Target price selector and email registration.
   - **Affiliate CMS Admin Modal**: Add custom affiliate products, delete products, and view real-time click logs.
   - **Legal & Info Modal**: Complete pages for Privacy Policy, Terms & Conditions, Affiliate Disclosure, Merchant Directory, Contact form, and Editorial Policy.
   - **Mobile Bottom Navigation**: Floating bottom bar with Home, Categories, Search, Wishlist, and Compare.

## 🚀 Running the Project Locally

```bash
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev

# 3. Build for production
npm run build
```
The website is served at `http://localhost:5173/`.
